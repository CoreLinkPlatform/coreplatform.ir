# Core Platform website design guardrails

This site is the umbrella identity for the Core Platform family.

## Brand architecture

- Core Platform is the parent brand.
- CoreLink is the connectivity product.
- Core Signal is the signal/insight product.
- Future documentation lives at docs.coreplatform.ir.
- Product identities may vary in accent, visual metaphor and motion, but typography, spacing, navigation logic and quality bar must feel related.

## Visual direction

Use the principles behind Leonxlnx/taste-skill `brandkit` and `taste-skill` when extending this site:

- Avoid generic SaaS hero composition, decorative gradients without meaning, glassmorphism-by-default, oversized pill UI and repeated card grids.
- Every visual device should communicate system structure, flow, state, topology or signal.
- Keep visual density controlled. This site should feel architectural, precise and technical rather than busy.
- Motion, if added, must explain relationships or state changes and respect `prefers-reduced-motion`.
- Maintain strong hierarchy, generous negative space and restrained accent colors.

## Product accents

- Core Platform: acid-lime / neutral dark — orchestration and system layer.
- CoreLink: cyan — topology, connection, route and normalization.
- Core Signal: warm coral — pulse, detection, meaning and action.

## Content rules

- Do not claim capabilities that are only planned or scaffolded.
- Prefer concrete system language over vague AI/innovation claims.
- Product links must remain cross-navigable across Platform, Link, Signal and Docs.
